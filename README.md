# 연소 탐험대

6학년 1~5반 학생이 반별 코드로 로그인해 연소 단원 시험을 치르고, 결과를 자동 제출하는 Next.js 웹앱입니다. 교사용 페이지는 별도의 비밀번호 세션으로 보호되며 Railway PostgreSQL에 점수를 저장합니다.

## 로컬 실행

1. `.env.example`을 `.env.local`로 복사하고 값을 채웁니다.
2. `npm install`
3. `npm run dev`

## 배포

Railway에 PostgreSQL 서비스를 추가하고, 웹 서비스의 `DATABASE_URL`을 PostgreSQL의 `DATABASE_URL` 참조 변수로 연결합니다. 나머지 환경 변수도 웹 서비스에 설정한 뒤 배포합니다. 앱은 최초 연결 시 필요한 테이블과 인덱스를 안전하게 생성합니다.

학생 결과의 이름과 번호는 교육 목적으로만 사용하고, 학교의 개인정보 보관 정책에 따라 관리·삭제해야 합니다.
